# Русский языковой пакет для Config Studio 🇷🇺

Официальный языковой пакет полной русской локализации для [Config Studio](https://github.com/EdvardBaldanov/config-studio).

## 🚀 Возможности
- Полный перевод всего интерфейса Config Studio на русский язык (настройки, проводник, редактор Monaco, аудит-лог, диалоги безопасности и тулбар).
- Автоматическая активация при установке.
- Добавляет `🇷🇺 Русский [Pack]` в выпадающий список языков в настройках и шапке редактора.

## 📦 Установка
В Config Studio откройте **Настройки (⚙️) → Плагины**:
1. Установите по ссылке GitHub:
   ```
   https://github.com/EdvardBaldanov/config-studio-lang-ru
   ```
2. Либо скачайте ZIP / `.cspkg` архив релиза и перетащите в окно настроек.
